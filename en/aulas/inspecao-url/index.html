Lesson 3 · 17 min

URL Inspection: indexed, discovered, unknown

Before you measure clicks, confirm the page is in the index. The Search Console URL Inspection tells you, page by page, whether Google knows it, crawled it, indexed it, and which address it chose as the official one. Each state calls for a different action. In this lesson you build the list of your key URLs and read the state of each one.

Start the lesson

In this lesson you will

  1. 1The four states that matter
  2. 2The right action for each state
  3. 3Why a batch of thin pages doesn't get in
  4. 4Build and check the list of key URLs

Goal: read the state of each key URL in the inspection and pick the right action for each state.

01 · From unknown to indexed

Click each state to see the action.

Click each block in the diagram to see what it does.

URL Inspection doesn't move a page up a step on its own. It tells you which step the page is on and what's missing.

02 · The key URL list and how to read it

Click each step.

1. The list

Pick the pages that need to be in the index: home, topic pages, catalog, new pages of the month.

Save them in a file called urls-chave.txt. It's the same list every week.

2. The inspection

In Search Console, paste each URL into the inspection bar. Write down the status, the date of the last crawl, and Google's canonical.

gsc_inspecionar.py does the same in batch, with credentials. The API is read-only: "Request indexing" is still a click in the dashboard.

At INEMAOn 10/05/2026, 12 of 14 key URLs were indexed. On 10/13, 13 of 14. /eventos/ was missing, "unknown to Google".

3. The batch that doesn't get in

Many similar pages published at once often get stuck at "discovered".

Before you ask for indexing again, compare the pages with each other.

At INEMA (09/23/2026)283 course pages were published in a single commit. Of a sample of 6, 5 were discovered and never crawled. Each page had 170 to 240 words, two randomly picked pages shared 47% of their vocabulary, the FAQ was identical, and the description was copied.

4. The link that disappeared

If an indexed page falls out again, look for what changed in the internal links.

A page with no server-rendered link becomes an orphan for the search engine.

At INEMA (09/30/2026)The /cursos/ page became "search only" and the 310 course pages lost their only server-rendered internal link. The fix was a collapsed index, with no visual change.

03 · The list, the command, and the log

Replace what's between < > with your own. The command needs a Google credential; without one, inspect in the dashboard.

04 · Practice: your key URLs

Start with the dashboard; the script is optional.

E1 · The list

15 min

Write urls-chave.txt with 10 URLs that must be in the index, all returning 200.

Done when: the file has 10 URLs from the same domain, one per line, and each one opens without errors.

E2 · The log with an action

40 min

Inspect the 10 URLs and fill in the log. For each one that is not indexed, write the action from the diagram.

Done when: the log has 10 rows with status, crawl date, and Google canonical, and every non-indexed row has a written action.
